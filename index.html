✅ How to Make Sure Everything Works

While SimParcel is designed to be simple, here are a few tips to ensure a smooth experience:

  • Keep Xcode Updated: The app works with the latest versions of Xcode and its simulators.
  • Have a Simulator Open: Before you start dragging, make sure your iOS Simulator is running. You can open it from Xcode by selecting "Open Simulator" from the top menu, or by pressing Cmd + Shift + 2.
  • Use the Latest Download: Always grab the newest version from the download page for the best experience and newest features.
  • Right-Click to Open: If macOS warns you about security, simply right-click (or Ctrl-click) the SimParcel app and select "Open" to bypass the warning the first time.
